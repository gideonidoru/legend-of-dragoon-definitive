# FMVHD

Restored cinematic pack for Legend of Dragoon: Definitive, independently enabled through Severed Chains' existing mod manager. Bundled by default. Existing campaigns use their normal mod-selection prompt to enable newly installed mods. Original videos remain the fallback when the pack is disabled, unavailable or incompatible with the disc source hash.

Code is AGPL-3.0 under the repository LICENSE. Enhanced videos are derived from original Legend of Dragoon footage and remain distinct from the code license. The user explicitly approved public distribution of these derived FMVHD assets as a project asset-policy exception on October 10, 2026; that policy exception is not a grant of rights by the original footage's owner.

The small code mod opens ordinary checksum-addressed movies from `gfx/fmvhd/videos/<sha256>.mp4` through the normal managed artwork link. Its complete data manifest must match the mod manifest, and each movie is size/hash-checked before opening. This avoids making a second cached copy. A manually installed legacy mod with embedded movies retains the bounded, verified cache fallback.

Large enhanced MP4s are published as individual checksum-pinned `file-<sha256>` objects in the current GitHub release, shared by source builds and runtime delivery, not committed as Git objects. The first split update imports verified unchanged movie entries from the installed hash-pinned legacy JAR into staging; later code-only updates reuse them without movie downloads. Full Reinstall deliberately fetches fresh payloads. No discs, extracted IKI files, decoded AVI masters, private saves or production cache are published. RealESRGAN and jPSXdec are external offline production tools, not engine runtime dependencies. Their notice links and pinned tool hashes are recorded in the production manifest.

First pack: 18 videos, logical 5:3 proportions, 1280x768 H.264, original 15 fps, 48 kHz stereo AAC. Original FMV playback halves XA volume; the enhanced audio encodes that same 0.5 gain. The normal FMV and master volume controls apply at playback.

Original fallback playback also follows played audio samples independently of presentation rate and gameplay speed. Separate bounded workers decode native video and ordered XA audio, including audio in the final EOF sector. Each movie has its own XA predictor history. A full output queue retains pending PCM; decoder starvation holds the media clock. Silent movies, unavailable audio output and a drained audio tail use elapsed active time. Pause preserves queued samples and excludes paused time from that clock. Skip, failure and completion close the workers and restore the previous rendering callback, pause observer and input tick rate.

Both original and enhanced movies show their skip prompt for 60 native frames (four active media seconds), independently of callback rate. New input received during a presentation stall gets its full lifetime from the first displayed media frame; a second matching input can still skip immediately, including while paused.

Headless validation fully decoded all 18 original movies: 31,177 native frames and 78,555,456 stereo sample frames. Synthetic tests cover presentation rates from 5 to 120 callbacks per second, output backpressure, delayed audio, long silent tails, pause and cleanup. The private source check can be repeated with `./gradlew originalMovieSourceProbe -PfmvOriginalFiles=<private-STR-folder>`; it retains no original pixels or PCM. The actual original-player lifecycle check uses `./gradlew originalFmvHandoffProbe -PfmvOriginalFile=<private-original-movie>` to cover paused stop and confirmed keyboard/action and mouse skip across all 48 gameplay rate/speed combinations, restoring the prior scope and releasing workers, audio sources and retained movie graphics without resuming gameplay. These checks do not establish physical Steam Deck or campaign acceptance.

For reproduction, run `scripts/restore-fmvhd.py` with paths to extracted original STR files, output folder, JDK, jPSXdec v2.1, RealESRGAN ncnn executable and model directory. The executable needs headless GPU access. Use a fresh output directory when changing the recipe. For offline production/bootstrap only, package finished records and videos with `scripts/package-fmvhd.py --production <output-folder> --output FMVHD-v0.1.0-videos.zip`. Work is resumable per validated asset and source hash and each video emits a completion record. The recipe uses Lanczos3 chroma, gentle temporal denoise and 75% framewise neural restoration blended with 25% conventional enlargement. It preserves timing and does not generate new motion. Offline format checks and rendered samples do not establish physical Deck performance or whole-campaign acceptance.

Source staging: `./gradlew fmvHdAssets` fetches the committed 18-name manifest from individual current-carrier objects; `-PfmvHdAssets=<approved-legacy-zip-or-SHA-movie-folder>` supplies an optional verified local bootstrap. `fmvHdJar` builds code and small metadata without video downloads. `stageDefinitivePackage` includes the staged artwork files. `fmvSplitSourceProbe -PfmvLegacyRelease=<private-hash-pinned-installed-release>` requires all 18 staged movies, opens them through a real managed artwork link and the actual small code JAR, fully decodes the enhanced videos, checks source metadata/timing and verifies legacy import without retaining original pixels or PCM. These headless checks do not establish physical Steam Deck acceptance.
