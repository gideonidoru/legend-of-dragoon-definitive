# ModelsHD custom geometry

These 19 custom battle model candidates were generated for Legend of Dragoon: Definitive from owner-provided, locally extracted US game models. The first surface pass refines eligible topology while retaining animation-part frames, material-face correspondence and held geometry where topology safeguards apply. The exact source identities, recipe and custom output checksums are in `roster.json`.

The Legend of Dragoon, its original character designs and underlying game assets belong to their respective rights holders. Preserve the project's upstream credits and notices. The source/mod code remains AGPL v3; that code license does not assign ownership of the underlying game designs or assets.

The owner explicitly approved publishing these custom ModelsHD deliverables and bundling them with the Definitive install on October 10, 2026. This folder contains the custom replacement candidates, not disc images, the original extracted data set or source-control packs. Individual face/costume reconstruction, gameplay/texture-mod acceptance and physical Deck validation remain pending.
