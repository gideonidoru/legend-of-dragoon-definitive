# FxHD

Independent effects artwork mod for Legend of Dragoon: Definitive. Bundled by the normal build; activate/deactivate through the existing game Mods menu.

Field batch 0.2 targets orthographic dust, smoke, both footprints and the central save-point glow with original timing, geometry, blending and source transparency retained. Other effects stay original. The cloud's actual dust-palette pairing has its own source-bound variant. Live source/palette mutations retain the indexed original route. Missing, corrupt or mismatched resources also retain originals.

The selected six 2x textures use 80 KiB before driver overhead. Loading uses the engine image cache and worker prewarming; no inference runs in game. See docs/definitive/FXHD_PRODUCTION.md and the public selection ledger for coverage.

This is development artwork. Native gameplay and physical Steam Deck acceptance remain separate from source, mask, lifecycle and package checks. Code is AGPL v3; game-derived artwork has the separate notices in ARTWORK-NOTICES.txt. Discs, original textures, diagnostic comparisons, weights and local inference tools remain private and are not installed.
