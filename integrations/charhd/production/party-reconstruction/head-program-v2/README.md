# CharHD: native-size party head candidates

**Superseded by the [registered surface correction](../head-program-v4/README.md).**
These earlier fits are retained as development history, not runtime or release art.

Eight normal party characters, with separate field and battle fits. These reuse
the custom head pipeline used for Dart's accepted live implementation. The original
in-game crown/jaw dimensions control scale; bodies and arms are unchanged.

The historical full-body Dart reconstruction and oversized head trials are not
selected. Dart's accepted runtime resources remain byte-identical.

See [construction, checks and remaining acceptance](../../../../../docs/definitive/PARTY_HEADS_NATIVE_SIZE.md).
`candidate-manifest.json` is an explicit development registry, not the normal
installer selection. `CPU-CONSTRUCTION.json` records 192 passing headless source
combinations, not native gameplay or physical Deck validation.

Custom assets are public. Preserve upstream AGPL, original character attribution
and the [TripoSR MIT notice](../../../../../experiments/dart-modelshd-charhd/reconstruction/TRIPOSR-LICENSE.txt).
