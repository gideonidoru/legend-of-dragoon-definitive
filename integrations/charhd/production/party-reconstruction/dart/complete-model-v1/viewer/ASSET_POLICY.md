# Public custom work, private game discs

The owner explicitly approved this policy on October 10, 2026: **all custom Definitive work should be public, versioned and included in the normal downloadable installation.** This includes mod code, ModelsHD geometry and HD artwork/texture upgrades. Producing custom work with the owner's game files does not by itself require a private download or a separate user authoring step.

ModelsHD 0.4 adds 8,531 generated custom part replacements under `integrations/modelshd/src/main/resources/modelshd/models/parts`, with complete checksums, recipe and coverage in `world-pass.json`. Its earlier 19 custom battle geometry candidates remain tracked under `integrations/modelshd/src/main/resources/modelshd/models/battle`. Their provenance, source identities and output checksums are recorded in the adjacent `roster.json`. The complete mod JAR is bundled into the verified Definitive game package and follows that package's installation, updates and rollback.

Game ISOs/disc images, full original extracted game data, source controls, private diagnostic dumps, saves, credentials and local runtimes remain excluded. Authoring tools may use a separate working folder containing controls and source material; publish the custom deliverables with their provenance rather than uploading that entire workspace.

Preserve upstream and third-party license/attribution notices. Permission to publish custom work is separate from visual acceptance, actual gameplay compatibility and Steam Deck performance. Label the current first geometry pass candidly; public delivery does not make it a finished character remaster.
