# UIHD

Independent interface restoration for Legend of Dragoon Definitive, development release 0.1.0.

The first production batch contains 64 selected custom PNGs: all 21 goods icons, ten element symbols, battle command frames, checkbox states, 15 menu-frame palettes, 14 item-icon palettes, the dialogue frame and dialogue arrow. Palette variants are resources, not additional screens. This is a production milestone toward whole-game UIHD, not completed full UI coverage or final AA visual acceptance.

Included by the normal Definitive build/installer; activation uses the game's existing Mods menu. The matching enhanced Definitive engine is required. Source-bound loading preserves display geometry, native transparency, live palettes and mod precedence. Shared image caching and prewarming respect graphics configuration. See [UIHD production](../../docs/definitive/UIHD_PRODUCTION.md) for coverage, engine integration, validation and remaining work.

Code: AGPL v3. See ARTWORK-NOTICES.txt for the separate status of game-derived custom artwork. Original game data, discs, model weights, inference runtimes and private comparisons are not bundled.
