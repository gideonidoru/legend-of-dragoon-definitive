# FMVHD code and data delivery

Spec: retain the approved 18 enhanced films as byte-identical individually checksum-managed `gfx/fmvhd/videos/<sha256>.mp4` files, with a small FMVHD code mod and canonical manifest. Preserve all seven mod IDs/switches, source identity, attribution, existing workspace artwork links and all playback/clock/decoder behavior. No old-client bridge and no independent publication; this is for the next coordinated release after frozen fb94.

The manager imports matching enhanced films from its hash-pinned installed legacy FMVHD JAR into staging only. It validates both archived metadata/source identity and complete extracted bytes; unsafe, duplicate, missing, corrupt, truncated and mismatched inputs are rejected. Failed import may use a verified network object; partial candidates cannot activate. Full reinstall intentionally downloads fresh files. Subsequent code-only updates reuse all movies; a one-film change downloads only that film.

Approved test seams are the installed-file lookup used by the mod, strict canonical manifest/package closure, actual FileDelivery/InstallStore update transactions with request-counting transport, legacy streaming import with source/archive closure, and headless resource opening/decoding. Required proof includes all 18 real payload hashes, normal managed gfx links, forbidden nested links/paths, switch/source/first-owner gates, request counts for initial split/code-only/one-film/repair/reinstall, cancellation and stream/resource cleanup. Synthetic tests do not establish physical Deck/GLES/campaign acceptance.

Source builds fetch the same 18 checksum-pinned `file-<sha>` movie objects used by runtime delivery, with committed manifest/provenance/notices. The historical aggregate ZIP digest only pins an optional local import/bootstrap input; no aggregate ZIP is emitted or required for next-format publication. Original IKI movies, disc images, extracted private inputs, decoded masters and production caches are excluded from public deliverables. Notices and provenance remain distinct from the code license. The coordinated publication owner controls asset reuse, exact-source gates, carrier promotion and pruning.
