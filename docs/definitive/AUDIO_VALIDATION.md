# Faithful audio validation

October 10, 2026. No new score, replacement voices, AI enhancement, stereo widening or extra reverb. Existing enhanced music synthesis defaults, XA resampling and half-volume gain are retained.

Headless local integration: 144 delivery cases, 140 passed, zero failures/errors and four window cases deferred; 22 ModelsHD cases passed. Nine new audio cases cover exact mono/stereo PCM samples, legacy native Opus counts and seeking, malformed/truncated inputs, selective migration, unpadded XA import, real OpenAL null-output final-tail drain, clean track replacement/stop and source recreation with an unplayed tail, recovery after naturally processed buffers and a 353-second accumulated playback clock rendered through actual OpenAL loopback without real-time waiting. Existing FMV audio/movie regressions also passed with actual enhanced-video and synthetic silent-tail fixtures. These checks do not play sound through the user's speakers or launch a game window.

A private isolated copy of previously prepared four-disc data was refreshed by the real headless disc-preparation entry point. It transformed four XA archives and wrote 41 PCM WAV recordings. All 114,307 previously extracted files, including legacy Opus, were verified unchanged by SHA256 against the original control folder. All 41 new clips passed complete error-failing FFmpeg decoding and format checks: 48 kHz signed 16-bit PCM, original mono/stereo layouts. Added data: 163,165,796 bytes (about 156 MiB); largest clip: 67,819,556 bytes, 16,954,878 stereo frames (about 353 seconds). A second preparation pass found no remaining conversions. Private images, source recordings, WAV outputs and diagnostic dumps are not release assets.

Lossless here means avoiding the previous additional 128 kbps Opus encode after the existing XA decoder/resampler. It does not recover detail removed by the original game's compression. The importer leaves unpacker version 5 and unrelated data alone; existing legacy Opus stays supported and remains available for rollback. A missing/incomplete WAV is refreshed from the installed discs; playback can use a complete WAV or fall back to the existing Opus. New lossless output uses more local storage and memory than compressed Opus. The measured largest file is about 65 MiB, below the 256 MiB per-recording bound.

Independent reviews found two recovery edges: naturally stopped queues can report zero offset before processed buffers are accounted for, and float duration accumulation can drift over a long track. Recovery now accounts for those buffers before seeking and uses a double accumulated clock; the existing public float clock API remains compatible. The new regressions passed, including all 16,944,000 loopback frames.

Audio-device recreation seeks the active recording back to its played position so queued but unplayed audio can be refilled. Buffer ownership also now permits detaching and freeing a never-started queue without deleting duplicate buffer names. Actual Deck sleep/resume, Bluetooth and headphones, long-running music/voice transitions, heavy-render-load dropouts and listening comparisons remain device acceptance. Source inspection and null-output tests do not establish audible improvement or hardware routing behavior.
