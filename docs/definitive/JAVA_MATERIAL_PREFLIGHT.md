# Private material atlas preflight

The optional offline atlas prototype now has an independent, bounded Java validator. It reads original model/TIM bytes before game container parsing or UV relocation, recomputes the complete palette crop and deterministic shelf layout, then exposes an immutable atlas/map pair only after all checks pass. This increment does not activate packs, change engine rendering, upload a GPU texture or alter the published alpha.

## Supported contract

- Standard 4-bit TIMs, CLUT widths 16/32/64 and 1–16 rows, source dimensions at most 512×512. The SC padded field TIM variant, mixed bit depths, CLUT-animation subfiles and extra container dependencies are rejected.
- Unpacked relative TMD containers, at most 256 parts, 100,000 total polygon packets and 5,000 textured faces. Original CLUT columns and rows are checked independently, and every UV must lie inside the matching TIM. This material reader checks packet and vertex/normal ranges; it is not a geometry, rig, animation or script validator.
- Exact model/TIM SHA256, 2×/4× integer scale, eight source texels of clamped padding, and every used palette exactly once in the reproducible sorted material map. Missing, moved, duplicated or partial entries reject the entire pack. Integer UV extrema supply the same crop bounds as the conservative floor-cell audit, including degenerate faces.
- A matching 8-bit RGBA PNG, no more than 4096×4096 or 32 MiB compressed. Full RGBA bytes are at most 64 MiB; decoding and validation also require temporary memory. Manifest reads are limited to 64 KiB, sixteen nesting levels and 4,096 values; duplicate keys, linked leaf files, non-regular files and fractional integer fields are rejected.
- STP alpha, all-zero discard and visible original black are checked for every material texel. Nearest controls and explicitly preserved palettes must match the original decoded RGBA8 pixels exactly. Unmapped atlas gaps must be all-zero, an additional Java constraint. Faithful mode retains the original indexed renderer; its floating-point five-bit shader colors need a separate native comparison tolerance.
- Neural descriptions accept only the existing pinned bin/parameter hash pairs and finite strength from zero to one. Those declarations do not prove that a specific generator ran, that a reconstruction is artistically correct, or that output distribution is licensed. Retained offline manifests/logs remain the generation evidence.

Implementation: [MaterialAtlas](../../src/main/java/legend/definitive/materials/MaterialAtlas.java), [SourceMaterials](../../src/main/java/legend/definitive/materials/SourceMaterials.java), and [read-only CLI](../../src/main/java/legend/definitive/materials/MaterialAtlasCheck.java). The module uses the game's existing Gson dependency and is excluded from the standalone portable manager JAR. No new runtime dependency is added to the installer.

## Reproduce privately

Use the project's Java 25 build setup and a recursive clone. Provide unchanged extracted originals and a pack generated by `scripts/pack-model-materials.py`; private inputs and outputs stay outside Git.

```sh
./gradlew --no-daemon --console=plain materialAtlasCheck \
  -PmaterialModel=/PRIVATE/characters/haschel/models/combat/32 \
  -PmaterialTim=/PRIVATE/characters/haschel/textures/combat \
  -PmaterialPack=/PRIVATE/haschel-packed-comparison
```

The CLI emits a JSON validation record containing input/output hashes, dimensions, palette count, checked material texels, RGBA bytes and `nativeRendering:false`. Invalid inputs fail without replacing game resources. It writes no asset output and does not boot the game.

Original fixtures can be checked without retail assets:

```sh
python3 -m venv /PRIVATE/visual-checks
/PRIVATE/visual-checks/bin/python -m pip install -r scripts/requirements-visual.txt
./gradlew --no-daemon --console=plain deliveryTest materialAtlasInterop \
  -PvisualPython=/PRIVATE/visual-checks/bin/python
```

Seven Java tests check immutable pairing, source/layout identity, exact original pixels, STP/discard/black, preserved neural regions, pinned weights, malformed packets, bounds, linked files, duplicate fields and empty packing gaps. Five cross-language tests generate original fixtures with conflicting palettes, degenerate UVs, quads, all supported CLUT widths and two rows at both scales, plus all pinned model descriptions. Python and Java accept the same controls and reject changed sources/maps/fractional scales/rehashed pixel tampering and unknown weight pairs. CI runs these cross-language checks on both package platforms; no weights or copyrighted inputs are needed. A transcribed weight hash was corrected before publication and this full-table regression was added.

## Verification and next step

Local Mac Studio / Java 25 compilation, the complete headless delivery suite and installer/Mac package assembly pass with gameplay tests disabled. The independently checked private cases and exact source checkpoint are recorded in [model coverage](MODEL_MATERIAL_COVERAGE.md). These checks establish material format consistency, not native sampling, blend modes, scene coverage, visual preference or physical Steam Deck performance.

Next implement a small, explicitly opted-in native control harness at the [audited vertex-construction seam](NATIVE_MATERIAL_INTEGRATION.md). Keep original geometry, keyframes and shaders; compare contrasting original palettes against the nearest atlas before neural artwork. Verify fractional boundaries, quantization, STP, resource ownership and teardown. Field and battle loading remain separate integration tasks. No default artwork switch is justified by this preflight alone.
