# FMVHD validation and remaining device acceptance

October 10, 2026. Engine runtime, mod cache, installation provisioning and production tools were reviewed against the FMVHD specification and repository standards. Two independent reviewers found no remaining blocking runtime issues after fixes to audio-tail completion, rumble boundaries, cleanup/fallback and decoder ownership. The packaging review also corrected incremental local-asset inputs.

Headless Mac verification against the integrated rendering/ModelsHD source: **123 delivery cases, 119 passed, zero failures, four window cases deferred**. Cases include real FFmpeg decoding with bounded queues and cancellation, actual OpenAL with the null output driver, cumulative played-audio time, a three-second video with a one-second audio tail, source identity, corrupted/truncated/oversized/symlink cache rejection, original-background installation with independent FMVHD provisioning, and rumble timing. Linux CI additionally generates its own synthetic ordinary and audio-tail movie fixtures. No game window or desktop automation was used locally.

All 18 completed outputs passed these checks. The video payload is 1,214,779,061 bytes; its pinned SHA256 is `c3dedfadb8659eead2444a434fe312faae9f304fe5fae00c0223163d6855419b`. Production checks require all 18 source-derived outputs to retain their decoded frame counts, 1280x768 geometry, 15 fps cadence and 48 kHz stereo audio, plus complete error-failing decoding and SHA256 checks. The public ZIP contains only enhanced MP4s and provenance/identity metadata. The recipe uses framewise animevideov3 restoration blended with conventional enlargement; it can soften texture and does not recover authentic source detail.

Visual sampling uses three points per film and consecutive-frame strips from the opening and Tree sequences. It is limited sampling, not whole-film viewing. The samples retain source motion blur, dark scenes, written overlays and embedded letterboxing. Extraction presentation-time warnings are counted in the manifest; some source frames land one frame ahead of their original presentation time in the decoded 15 fps master. These warnings are not hidden by a successful decode check.

Physical Steam Deck acceptance remains open: smooth playback and sound, audio drift over the longest ending, controller binding-aware two-step skipping, rumble, normal return to gameplay, independent mod disabling, original fallback and audio-device reconnect. Offline tests and package assembly do not establish those device behaviors. Existing campaigns use the engine's normal installed-mods-changed selection prompt.
