# Haschel authored-skin prototype

This authoring-only experiment starts the facial surface from a uniform base, rather than retaining a second inferred face underneath a new painting. It produces editable custom geometry and paint. See `integrations/charhd/production/party-reconstruction/authored-skin-program-v1/README.md` for inputs, reproduction and the explicit visual/runtime limitations.

It does not alter the engine, installer, accepted Dart, or normal CharHD selection. It is deliberately scoped to Haschel while geometry, ear registration and neck attachment are evaluated. The sampling helper is specific to this prototype and should not replace the general party baker.
